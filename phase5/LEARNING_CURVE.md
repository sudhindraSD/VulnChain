## 1. Setup and pre-declared choices

- **dim-6 graph:** no `no-dim6` branch exists in this clone (`git branch -a` shows `main`, `hybrid-cs`, `learning-curve` only). The neutralisation was therefore created here, in memory, and `Package.x[:,6] == 0` was asserted on all **12,405** packages — **passed** (977 packages had dim 6 = 1 before neutralisation). No data file was written or modified.
- **Train repos:** 50 repos = every repo in `_metadata.node_repo_sources` except `practica` (val) and `saleor-storefront` (test). Val/test repos stay FIXED in all runs.
- **Subsets:** fractions `[0.25, 0.5, 0.75, 1.0]` × nested prefixes of a repo ordering; ordering seeds `[1, 2, 3]`; 100% has one ordering. `k = ceil(fraction * 50)` (declared before the run). Nesting was asserted for each ordering.
- **Induced graph:** union of the lockfile closures of kept train repos + val + test (`repo_sources`). All CVE / Author nodes retained; `dependsOn` kept only when both endpoints survive; `hasVulnerability` / `maintainedBy` kept only when the Package endpoint survives.
- **Masked-50 seeds:** `[42, 123, 456, 789, 1024]`; ratio 0.50; official `apply_edge_mask`, `run_model_inference`, `run_label_prop_baseline`, `compute_auc`.
- **HR recipe (exact, unchanged):** `phase5/phase1_head_refit.py` — frozen encoder `vulngat_51repo.pt`, fresh `Linear(128,1)+Sigmoid` head, MSE only, Adam lr=0.001, batch=32, max 500 epochs, patience 50, seed 42, checkpoint on **val Spearman** (non-zero val nodes). Zero hyperparameter changes.

**Applied amendments (previous Task B):**

1. **A1 train-loss mask.** A node is in the training loss only if it is `train` in `repo_split_mapping_51repo.json` AND ≥1 of its `repo_sources` is in the KEPT train repos. Mapping-train nodes whose only train-repo sources were dropped are **excluded from the loss** (not reassigned to test, not used as train) but stay in the graph for message passing.
2. **A2** `n_train_loss_nodes` and `n_excluded_dropped_provenance_nodes` are printed per subset (columns below).
3. **A3** the 645 / 8,682 identity assertions and the val/test label assertion are kept, unchanged.
4. **A4 time-box** = one working day = 8 h wall clock; if the full run is not done, stop, report completed rows, do not extend.
5. **A5** `wall-clock train (s)` column added.

## 3. Assertions and STOP

- Full-graph evaluated sets: **645 positives** (official `select_eligible_packages(0.70)`, which auto-relaxes to 0.30) and **8,682 negatives** (VPSS = 0).
- Assertion A (identical 645 / 8,682 sets in every induced graph): **FAIL**.
- Assertion B (test/val labels on evaluated sets match full-graph values after `vpss_labeler.label_all()` on each induced graph): **FAIL**.

> **STOPPED — Assertion A FAILED in 9/10 runs: e.g. 25%/ordering 1 keeps only 285/645 positives and 5,307/8,682 negatives — the induced subgraphs drop 360 positives and 3,375 negatives, so the evaluated sets are NOT identical across subsets. Only 100% of train repos retains all of them. Assertion B FAILED in 9/10 runs: recomputed VPSS on the induced graph differs from the full-graph value on up to 242 evaluated nodes (the val ∪ test ∪ 645-positive ∪ 8,682-negative union present in the graph; 25%/ordering 2); only 100% reproduces the full-graph labels.** No model was trained, no masked-50 AUC or LP_clean AUC was computed, and no rerun, tuning, or second mask was attempted, exactly as instructed.

**Training stage:** not implemented in this script and not executed. The prompt requires stopping at the first failed assertion, so writing an unexercised training loop would misrepresent the protocol. The exact recipe that would have been used, unchanged, is recorded in §1. Consequently the seven result columns that depend on training are `not run`, and the per-fraction aggregation and the 50%→100% gain cannot be computed.
