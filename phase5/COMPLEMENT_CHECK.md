## 2. Definitions fixed before running

- **Evaluated set** = `pos + never_vuln_indices`, i.e. exactly the nodes that enter the official `compute_auc` for that seed (masked positives first, then the shared never-vulnerable negatives). The same mask instance, the same positive set and the same negative set are used for HR, LP_clean and both fusions.
- **rank-avg** = `0.5 * rankdata(HR_eval, method='average') + 0.5 * rankdata(LP_clean_eval, method='average')`, ranks taken over the evaluated set. Average ranks for ties are used so that tie-breaking cannot favour the positives, which are placed first in the index list.
- **z-avg** = `0.5 * z(HR_eval) + 0.5 * z(LP_clean_eval)`, each vector standardized over the evaluated set with population std (`ddof=0`).
- Both fusion AUCs are obtained by placing the fused values back into a full-length vector and calling the **official `compute_auc`** with the unchanged `pos` / `never_vuln_indices` lists.
- **corr(all)** = Spearman ρ between HR and LP_clean over the evaluated set. **corr(positives)** = Spearman ρ between HR and LP_clean over the masked positives only, ranks recomputed within that subset. Spearman ρ is the Pearson correlation of the average-tie rank vectors.
- Fusion weights were declared at import as `W_HR = W_LP = 0.5`. No weight search, no per-seed choice, no post-hoc selection.
