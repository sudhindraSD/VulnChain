### Protocol decisions where the specification was underdetermined

These were fixed **before** the run and are reported so nothing is hidden; they were not changed after seeing any result.

1. **Smooth-step recurrence.** Both steps use the same recurrence form `X <- (1-alpha)*X0 + alpha*S@X` for `n_iter` iterations, matching the explicitly specified correct-step formula and 'same alpha / n_iter'. Known labels are fixed in the anchor `Y0` (`Y0[known] = label_clean[known]`); known nodes are **not** re-clamped on every iteration. Some C&S implementations do re-clamp; that variant was not used.
2. **No residual scaling / no autoscale.** The spec says E is 'added to base scores'; no learned scale factor is applied.
3. **Ridge target.** The repo's ridge-raw recipe is `Ridge(alpha=1.0)` on the 10 raw Package features fitted on `masks['train_mask']`, with the archived diagnostic's sigmoid applied to predictions (`phase5/phase2a_mlp_reconverge.py`, `phase5/WORKER_REPORT_PHASE5.md`, `phase5/part_c_epss_arms.py`). Its regression target is here `label_clean` (masked-graph VPSS), **not** the repo's `data['Package'].y`, because `HYBRID_GATE.md` §3 forbids original labels in label-consuming hybrid components. `alpha=1.0` is used directly (the repo's reported val-MSE-selected value) so no second grid is run.
4. **Adjacency normalisation, tie-break, RNG seeds, sanity tolerance** are declared as module constants: symmetric normalisation with self-loops; strict-`>` grid selection (first combo wins ties); bootstrap seed `20261114`, permutation seed `20261114+seed`, `SANITY_TOL = 0.05` ('near 0.5' = |mean − 0.5| ≤ 0.05).

## 9. Limitations carried into the paper (from `HYBRID_GATE.md`)

1. `compute_own_vpss` unit mismatch (`own_raw = Σ CVSS/10` divided by unscaled `raw_sum`) forces the documented 0.30 auto-relaxation → N=645.
2. `apply_edge_mask` removes **all** CVE edges of ~50% of eligible *packages*, not 50% of edges (plus a forced floor of 3).
3. Negatives are shared from the **original** labels for every method and are not recomputed on the masked graph.

Additional structural facts of this protocol, stated without interpretation: the unknown set is exactly the masked positives and the never-vulnerable negatives are always in the known set; therefore known/unknown status is aligned with the evaluation class partition, and `label_clean` is 0 for every negative. The smooth-step anchor `Y0[known] = label_clean[known]` carries that fact into the final score vector.
